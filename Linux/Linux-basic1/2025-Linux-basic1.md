## 1. 너는 누구냐? - whoami 명령어

반갑다 훈련병! 나는 앞으로 자네의 리눅스 여정에 함께할 원 아이드 잭 병장이라고 한다! 줄여서 원병장이라고 부르도록!

자네의 이름은 무엇인가?

뭐라고?? 이름도 모른다고? 이거 갈 길이 멀구만!

지금 당장 `whoami` 명령어를 사용하여 이름부터 알아오도록!!!

#### **지시사항**

`whoami` 명령어를 이용해 로그인한 사용자가 누구인지 알아내 봅시다.

**실행** 버튼을 눌러 자유롭게 디렉토리들을 탐색해보며 로그인한 사용자의 이름을 알아보세요.

알아온 이름을 `main.sh`의 `user_name` 변수에 저장해주세요.

- **주의** : 정확한 채점을 위해서는 변수의 이름을 변경하면 안되며, 아래 예시와 같이 띄어쓰기 없이 입력해주세요.

#### 입력 예시

```
user_name=james
```

입력을 완료했다면 `제출` 버튼을 눌러 채점 결과를 확인해보세요.

#### **Tip.**

`id -un`은 `whoami` 명령어와 동일한 역할을 수행합니다. 사용하면 현재 여러분이 사용하고 있는 계정의 ID를 확인 할 수 있습니다.

사용자 계정은 `/etc/passwd` 폴더에 저장되고 관리되어집니다.



## 2. 디렉토리 이동과 확인

다시 보니 반갑네 훈련병! 자네의 이름을 알았으니 이젠 다음 훈련으로 넘어가도 될 듯 하네.

이번 시간에는 디렉토리를 이동해보고 이동한 디렉토리의 경로를 확인해보는 훈련을 할걸세.

디렉토리를 이동하고자 할 땐 어떤 명령어를 사용해야 하는지 기억하나? 바로 `cd` 명령어라네! `cd 디렉토리명`으로 원하는 디렉토리로 이동할 수 있지.

그렇다면 어떻게 다른 디렉토리로 이동했는지 알 수 있냐고? `pwd` 명령어를 이용하면 현재 있는 경로를 쉽게 알 수 있다네, 훈련병!

그럼 `cd` 명령어를 이용하여 디렉토리 내부에 있는 목표 `quiz` 디렉토리로 이동하고, `pwd` 명령어를 이용하여 해당 경로를 확인하고 입력해주게! 자네를 믿는다네!

#### **지시사항**

`cd` 명령어를 이용해 디렉토리를 이동해보고, 이동한 디렉토리의 경로를 직접 확인해보겠습니다.

- 디렉토리 이동 순서

1. `hello` 디렉토리로 이동
2. `hello` 디렉토리 내 `nice` 디렉토리로 이동
3. `nice` 디렉토리 내 `quiz` 디렉토리로 이동

**실행** 버튼을 눌러 자유롭게 디렉토리들을 탐색해보며 목표 디렉토리인 `quiz` 디렉토리로 이동하고, 해당 디렉토리의 경로를 확인해보세요!

확인한 경로를 `main.sh`의 `directory_path` 변수에 저장해주세요.

- **주의** : 정확한 채점을 위해서는 변수의 이름을 변경하면 안되며, 아래 예시와 같이 띄어쓰기 없이 입력해주세요.

#### 입력 예시

```
directory_path=hello/world/nice
```

입력을 완료했다면 `제출` 버튼을 눌러 채점 결과를 확인해보세요.

#### **Tip.**

터미널 내에 있는 글을 복사하고 싶을 때는 Ctrl+c 대신 `Ctrl+Insert` 를 누르면 됩니다.

디렉토리 내부에 있는 디렉토리로 이동할 때에는 cd 명령어를 여러번 사용해도 되지만, 원하는 디렉토리의 경로를 입력하여 한번에 이동할 수 있습니다.



## 3. 숨겨진 파일과 디렉토리

이번에는 디렉토리를 이동하고, 디렉토리의 내부 구조를 확인하는 훈련을 진행할걸세.

이미 이전 훈련을 통해 디렉토리를 이동하는 방법은 알고 있겠지?

다음은 디렉토리 내부 구조를 확인하는 훈련일세! `ls`는 우리가 이동한 디렉토리 내부에 어떤 파일이나 폴더(디렉토리)들이 있는지 확인시켜 주는 명령어라네.

그런데 자네 `ls`의 옵션을 잘 숙지하고 있는가? 옵션은 다음과 같다네!

- `ls -l` : 현재 디렉토리의 목록을 상세히 출력
- `ls -a` : 숨겨진 파일이나 디렉토리를 포함하여 출력

그럼 `-l`과 `-a` 옵션의 사용법을 구별하여 `cd`와 `ls` 명령어 훈련을 진행하도록!

#### **지시사항**

`cd` 명령어를 이용하여 welcome 디렉토리로 이동한 뒤에 폴더(디렉토리)내에 몇개의 파일이 있는지 `ls` 명령어와 여러가지 옵션들을 이용하여 확인해 봅시다.

welcome 디렉토리에 몇 개의 **파일**이 있나요? `실행` 버튼을 눌러 터미널에서 숨겨진 파일의 개수를 확인해보세요.

확인한 파일의 개수를 `main.sh`의 `file_count` 변수에 저장해주세요.

- **주의** : 정확한 채점을 위해서는 변수의 이름을 변경하면 안되며, 아래 예시와 같이 띄어쓰기 없이 **숫자**만 입력해주세요.

#### 입력 예시

```
file_count=1000
```

`제출` 버튼을 누르면 채점 결과를 확인할 수 있습니다.
