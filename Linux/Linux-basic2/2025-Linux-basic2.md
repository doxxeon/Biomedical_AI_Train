## 1. 파일 권한 수정하기

이번엔 `chmod` 명령어를 이용하여 파일의 권한을 바꾸는 연습을 해보도록 하겠다.

여러 사용자가 공동으로 작업하는 환경에서는 파일의 권한 관리를 철저하게 하는 것이 중요하지.

아무나 수정할 수 없고, 아무나 실행할 수 없도록 주어진 파일을 바꾸는 것이 이번 실습의 목표이다!

#### **지시사항**

`directory` 폴더 내에 존재하는 hello.py의 권한을 바꾸어 보겠습니다. 현재 `hello.py`파일은 누구나 수정할 수 있게 설정되어 있는 상태입니다.

- **소유자**는 모든 권한을 가지고
- **그룹**은 읽고 실행만 가능하며
- **그 외의 사용자**는 오로지 읽는 것만 가능
  하도록 파일의 권한을 수정해주세요.

**실행** 버튼을 눌러 터미널에서 정답 명령어를 알아보고, `main.sh`에 명령어들을 입력해주세요.

입력을 완료했다면 **제출** 버튼을 눌러 채점 결과를 확인할 수 있습니다.

#### **Tip**

우리가 권한을 수정하길 원하는 파일은 `directory`라는 폴더(디렉토리) 안에 존재하고 있습니다.

폴더(디렉토리)안의 경로를 표현하기 위해서는 `/` 를 사용합니다. 예를 들어, `directory` 폴더 내의 `example.py` 의 경로를 표현하는 방법은 다음과 같습니다.

```
directory/example.py

```

`chmod`명령어를 사용할 때 `chmod [파일 권한] [이름 및 경로]`를 사용할 수 있다는 것을 생각해서 문제를 풀어보세요



## 2. 디렉토리와 파일 생성

이번 시간에는 새로운 디렉토리와 파일을 생성하는 훈련을 해볼걸세

우리의 목표는 새로운 디렉토리 `best`와 `army`를 생성하고 각 디렉토리 안에 새로운 빈 파일인 `korea`와 `awesome` 을 생성하는 거라네

새로운 디렉토리를 생성하기 위해서는 `mkdir` 명령어를 이용할 수 있다는 것을 기억하고 있겠지? 다음과 같이 입력하면 원하는 이름의 디렉토리가 새로 생성되지!

```
mkidr 생성할 디렉토리 이름

```

그렇다면 빈 파일을 생성하는 명령어는 무엇이냐고? 그건 바로 `touch`라네 훈련병!
마찬가지로 다음과 같이 입력하면 원하는 이름의 파일을 새로 생성할 수 있지! 여기서 성생되는 파일은 빈 파일이라는 것을 잊지말게나!

```
touch 생성할 파일 이름

```

자 그럼 디렉토리와 파일을 생성해볼까?

#### **지시사항**

`mkdir` 명령어를 이용해 `best` 디렉토리와 `army` 디렉토리를 생성하세요.

디렉토리 생성이 완료되었다면 `best` 디렉토리 안에는 빈 파일 `korea` 를 생성하고, `army` 디렉토리 안에는 빈 파일 `awesome`을 생성하세요.

**실행** 버튼을 눌러 터미널에서 정답 명령어를 알아보고, `main.sh`에 명령어들을 입력해주세요.

입력을 완료했다면 **제출** 버튼을 눌러 채점 결과를 확인할 수 있습니다.



## 3. 파일 옮기기

`mv` 명령어를 이용하면 파일을 다른 디렉토리로 이동시킬 수 있다네.

앞선 훈련에서 파일의 권한을 수정해 보았으니, 이번에는 `mv`명령어로 파일을 특정 디렉토리내로 이동시키는 실습을 한 번 해보도록 하겠다!

그럼 준비하도록!

#### **지시사항**

`directory` 폴더 내에 존재하는 `hello.py`와 `myname`파일을 각각 `greeting`, `myinformation`디렉토리 내로 이동시키려 합니다.

`greeting`과 `myinformation` 디렉토리는 동일한 `directory` 폴더 내에 존재합니다.

`mv`명령어를 사용하여 위의 파일들을 각각의 디렉토리 내로 이동시켜 주세요.

**실행** 버튼을 눌러 터미널에서 정답 명령어를 알아보고, `main.sh`에 명령어들을 입력해주세요.

입력을 완료했다면 **제출** 버튼을 눌러 채점 결과를 확인할 수 있습니다.



## 4. 파일 복사하기, 디렉토리 삭제하기

`cp` 명령어는 `mv`명령어와는 달리, 파일이나 디렉토리를 특정 디렉토리로 **복사**할 수 있지.

그리고 `rm` 명령어는 파일이나 디렉토리를 삭제할 수 있는 명령어라네.

이 두 명령어를 자유자재로 사용할 수 있도록 해주는 다양한 옵션 사용 방법은 숙지했겠지?

그렇다면, 다음 지시사항을 실행한다. 실시!

#### **지시사항**

`directory` 폴더 내에 존재하는 모든 파일들을 복사하여서 새로운 디렉토리인 `elicer_infor`로 옮기려고 합니다.

`cp`명령어를 사용하여 `directory`폴더를 새로운 디렉토리 로 이동시키고 원래 있었던 `directory`폴더를 `rm`명령어를 사용하여 삭제해 주세요

최종 tree 형태는 다음과 같이 구성됩니다.

```
elicer_infor
    - directory
        - greeting
            - hello.py
        - myinformation
            - myname
main.sh

```

**실행** 버튼을 눌러 터미널에서 정답 명령어를 알아보고, `main.sh`에 명령어들을 입력해주세요.

입력을 완료했다면 **제출** 버튼을 눌러 채점 결과를 확인할 수 있습니다.

#### **Tip**

디렉토리 내 모든 내용을 `cp`명령어를 이용하여 복사하기 위해서는 `-r`옵션을 사용하면 됩니다.



## 5. 명령어로 파일 내용 작성하기

`cat` 명령어로 파일의 내용을 읽을 수 있다는 점은 모두 숙지했나?

좋아! 그렇다면 `cat` 명령어에 `>`와 `>>`를 이용하여 파일에 내용을 적을 수 있다는 것도 알고 있겠지?

이번엔 `cat` 명령어로 파일의 내용을 작성하는 훈련을 진행하겠다. 지시사항과 표준 입출력에 유의하여 명령어를 작성하도록!

#### **지시사항**

`cat`명령어를 이용하여 `greeting` 디렉토리 내에 존재하는 `hello.py`의 내용에 `answer.txt`내용을 추가해봅시다.

`cat`은 파일을 열어서 표준 출력 스트림(stdout)으로 우리에게 보여주는 명령어 입니다. 그렇다면 `answer.txt` 파일에 적혀진 내용을 출력스트림으로 stdout이 아닌 `hello.py` 파일을 사용하면 되겠죠?

**실행** 버튼을 눌러 터미널에서 정답 명령어를 알아보고, `main.sh`에 명령어들을 입력해주세요.

입력을 완료했다면 **제출** 버튼을 눌러 채점 결과를 확인할 수 있습니다.

**정확한 채점을 위하여 `answer.txt`, `hello.py` 파일을 직접 수정하지 말아주세요. 오타가 발생하거나 다른 문장을 입력하면 정확한 채점이 되지 않습니다.**
