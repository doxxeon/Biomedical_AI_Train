## 2. File Redirection

이번 실습은 `<` `>`의 정확한 이용방법을 숙지한 훈련병만 통과할 수 있다!

다시 한번 기억해보자면 `>` 연산자는 **표준 출력**을 재지정하고, `<` 연산자는 **표준 입력**을 재지정한다네.

리눅스의 File Redirection 기능을 잘 공부했다면 텍스트 파일을 파이썬 코드의 입력값으로 넣어주고, 그 파이썬 코드의 출력값을 다른 텍스트 파일로 나오게 하는 것 쯤은 식은 죽 먹기지.

그럼 지금 당장 아래 지시사항을 읽고 임무를 완수한다. 실시!

#### **지시사항**

`input.txt`를 입력스트림으로 사용하여 `add.py` 파일로 데이터를 보내려고 합니다.

`add.py`의 내용은 아래와 같습니다.

```
number = input()
answer = int(number) + 3
print(answer)

```

`add.py` 코드를 실행하고, 실행한 파일의 결과값을 `output.txt`에 저장하는 명령어를 작성해주세요.

**실행** 버튼을 눌러 터미널에서 정답 명령어를 알아보고, `main.sh`에 명령어들을 입력해주세요.

입력을 완료했다면 **제출** 버튼을 눌러 채점 결과를 확인할 수 있습니다.

#### **Tip.**

`add.py`와 같은 파이썬 코드를 실행하기 위해서는 `python` 명령어를 사용하실 수 있습니다. 아래는 add.py파일을 실행하는 예시입니다.

```
python add.py
```



## 3. Pipe와 입력스트림의 차이점

이번 훈련에서는 Pipe 와 File Redirection의 차이점을 확인해보도록 하겠다.

File Redirection에서는 파일을 표준 스트림으로 사용했다면, Pipe는 각 프로세스가 다른 프로세스를 표준 입력 스트림으로 사용한다는 점이 다르다.

예를 들자면, `input.txt`의 내용 자체를 파이썬 코드의 입력값으로 넣어주는 것은 File Redirection이고,

`cat input.txt` 명령어 프로세스의 출력 결과를 파이썬 코드가 입력값으로 사용하는 것은 Pipe인 것이다.

아래 지시사항을 파악하고 Pipe와 File Redirection의 차이를 잘 생각해보도록!

#### **지시사항**

`input.txt`를 `cat`을 이용하여 출력해주세요.
출력된 값을 pipe를 사용하여 `add.py`파일의 표준입력값으로 사용해주세요. 마지막으로 최종결과를 `output.txt`에 저장해주세요.

**실행** 버튼을 눌러 터미널에서 정답 명령어를 알아보고, `main.sh`에 명령어들을 입력해주세요.

입력을 완료했다면 **제출** 버튼을 눌러 채점 결과를 확인할 수 있습니다.
