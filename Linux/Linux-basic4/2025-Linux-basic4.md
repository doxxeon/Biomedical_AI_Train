## 1. 프로세스 확인하고 종료해보기

프로세스가 무엇인지 알았으니 현재 우리가 사용하고 있는 프로세스가 어떤 것이 있는지 확인해보겠다.

앞에서 배운 `ps` 명령어를 실행하면 여러 개의 프로세스가 있는 것을 확인할 수 있지. `ps` 명령어에는 다음과 같은 여러 옵션들이 있다네

- 모든 프로세스 리스트 확인

```
ps -ef

```

- 시스템에서 실행 중인 모든 프로세스 출력

```
ps -aux

```

많은 프로세스가 실행된다면 당연히 그만큼 메모리가 사용될 것이고, 다른 프로그램의 속도에 영향을 미칠 것이 분명하므로 우리는 필요 없는 프로세스를 없애는 실습을 해볼 것이다!

프로세스를 없애는 명령어는 `kill`이었지! `kill`에도 마찬가지로 다양한 옵션들이 있네.

- 프로세스 강제 종료

```
kill -9 프로세스ID

```

- 프로세스 정상 종료

```
kill -15 프로세스ID

```

위와 같이 입력하면 원하는 ID의 프로세스를 종료시킬 수 있다네.

확인한 프로세스들 중 `makeprocess.out`은 아무런 기능을 하지 않는 의미없는 프로세스다.

자, 메모리를 낭비하는 일이 없도록 당장 위의 프로세스를 종료시키도록!

#### **지시사항**

`ps` 명령어와 다양한 옵션들을 사용하여 실행 중인 프로세스를 확인해보세요.

확인한 프로세스들 중 `makeprocess.out` 프로세스의 ID 를 찾아 `kill` 명령어를 사용하여 프로세스를 종료시켜보세요.

#### **Tip**

명령어를 수행하게 되면 가장 아래에 우리가 사용한 명령어의 프로세스를 볼 수가 있습니다.

그러나 해당 명령어 프로세스를 종료시키려고 하면 이미 존재하지 않는 프로세스라고 나오죠.

이는 shell이 명령어를 수행할 때 새로운 프로세스를 생성하고 그 프로세스 내에서의 결과를 우리에게 보여준 후 프로세스가 종료되어 버리기 때문에 이러한 현상이 발생하는 것입니다.

#### **추가 실습**

shell을 `Ctrl + c` 나 [정지]버튼을 누르지 않고 종료시켜 보세요! 리눅스에서 새로운 shell을 만들려면 어떻게 해야하는지 생각해보고 shell실행 프로세스를 찾아서 종료해보세요!



## 2. 백그라운드 프로세스 확인과 종료

우리는 앞에서 백그라운드를 확인하는 방법을 `jobs`라는 명령어로 알아보았다. 그렇다면 백그라운드에서 명령어를 실행하는 방법 또한 알아봐야겠지!

이미 알고 있겠지만, 백그라운드에서 명령어를 실행하는 방법은 원하는 명령어 뒤에 `&` 를 붙이면 된다!

그럼 아래 지시사항대로 백그라운드에 프로세스가 동작하도록 명령어를 작성하고, 프로세스 목록까지 출력해라. 실시!

#### **지시사항**

`time.py` 파일에 60초를 세는 간단한 python script가 준비되어 있습니다.

`&`를 사용하여 백그라운드에서 위의 파이썬 파일을 실행해보고 `jobs`또는 `ps`명령어를 사용하여 백그라운드에서 주어진 작업이 실행되고 있는지 확인해 보세요.

#### **Tip.**

백그라운드에서 실행되는 프로세스를 포그라운드로 가져와야 할 경우가 있을 수 있습니다.

`fg` 와 `bg`를 이용하여 위의 작업을 실행할 수 있는데 정지되어 있는 프로세스를 백그라운드에서 실행시키기 위해 먼저 프로세스의 작업번호를 `jobs`명령어로 확인 후 ..

```
fg [jobs id] ## 포그라운드로 프로세스 실행
bg [jobs id] ## 백그라운드로 프로세스 실행

```

위와 같이 프로세스를 실행 시킬 수 있습니다.

**이번 실습에서는 main.sh를 사용하지 않습니다. 실행버튼을 눌러 자유롭게 디렉토리들을 탐색해보세요.**
